# **App Name**: Casa Origen

## Core Features:

- Cultural Storytelling Hub: An immersive digital history feature celebrating the Ciénaga Caiman tradition and the local fishing heritage.
- Gastronomic AI Concierge: A smart tool that suggests food and beverage pairings based on local Ciénaga flavors and personal user preferences.
- Visual Interaction Menu: A masonry-style categorized digital menu allowing users to explore fresh coastal dishes and seasonal cocktails.
- Seamless WhatsApp Handover: A conversion-optimized cart system that translates food selections into structured WhatsApp orders for rapid processing.
- Database-Backed Reservations: A robust booking system for managing table availability and special event dates in a central database.
- Event Ingestion & Quoting: An automated form-to-lead system for weddings and corporate gatherings with status tracking via the admin dashboard.
- Merchant Operations Suite: A secure administrative portal to manage live menu inventory, review incoming reservations, and update the heritage gallery.

## Style Guidelines:

- Primary color: Sand Brown (#B79D84), evoking coastal warmth and refined heritage.
- Background: Bone White (#FAF8F5), maintaining a breathable and sophisticated Mediterranean-Caribbean aesthetic.
- Accent: Caribbean Sea (#6E9FA8), providing a refreshing, desaturated contrast that represents the breeze and water.
- Headline font: 'Playfair Display' (Serif) for elegance and handcrafted sophistication. Body font: 'Inter' (Sans-serif) for high readability and objective modernism. Note: currently only Google Fonts are supported.
- Editorial grid layout with ample negative space to convey coastal luxury and cultural depth.
- Bespoke line-art icons referencing regional artifacts like the caiman and traditional Ciénaga architecture.
- Gentle parallax scrolling and organic fades to simulate the rhythmic movement of palm trees and ocean tides.
